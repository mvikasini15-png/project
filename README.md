# 🌱 KANI HUB – Organic Fresh Farm Store

**KANI HUB** is a web-based organic fresh farm store designed to make it easy for customers to explore and purchase fresh fruits and vegetables online.

The project provides a simple and user-friendly shopping experience with product categories, cart management, billing, user login, payment confirmation, and order-related features.

## 🚀 Features

* 🏠 Home page with featured products
* 🥬 Fresh fruits and vegetables
* 🔍 Product browsing and categories
* 🛒 Add to cart and cart management
* 💰 Automatic bill calculation
* 🧾 Invoice generation
* 👤 User login
* 🔐 Admin login
* 💳 Payment confirmation
* ⭐ Customer feedback
* 📱 Responsive design
* 🚚 Delivery information
* 🌱 Organic and fresh-farm product information

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Website functionality and interactions
* **Local Storage** – Temporary storage of cart/user-related data
* **HTML2PDF** – Invoice generation

## 🎯 Project Objectives

1. To provide an easy online shopping platform for fresh farm products.
2. To allow customers to browse fruits and vegetables conveniently.
3. To provide simple cart and billing functionality.
4. To generate a digital invoice for orders.
5. To provide a user-friendly and responsive web interface.
6. To demonstrate the use of HTML, CSS, and JavaScript in developing an e-commerce website.

## 🌿 Why KANI HUB?

KANI HUB focuses on connecting customers with fresh farm products through a simple digital shopping experience.

The website is designed around the idea of:

> **Fresh from Farm, Naturally to You.**

## 💻 How to Run the Project

### Method 1 – Using VS Code

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Open `index.html`.
4. Right-click the file.
5. Select **Open with Live Server**.
6. The website will open in your browser.

Example:

```text
http://127.0.0.1:5500/index.html
```

### Method 2 – Directly in Browser

You can also open `index.html` directly in a web browser if the project does not require a local server.
